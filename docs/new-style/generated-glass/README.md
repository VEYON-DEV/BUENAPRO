# Referencias BuenaPro Glass

Coleccion visual generada el 2026-08-03 para definir la nueva direccion de BuenaPro antes de modificar las vistas productivas.

## Pantallas

1. `01-login.png`: acceso con fotografia, oportunidad flotante y formulario compacto.
2. `02-registro.png`: alta de cuenta con progreso, datos empresariales y continuidad visual con Login.
3. `03-inicio.png`: radar diario, prioridades, mercado y competidores.
4. `04-oportunidades.png`: busqueda, filtros, tabla operativa y vista rapida sin historico.
5. `05-detalle-oportunidad.png`: traza de decision, requisitos, TDR e historico comparable.
6. `06-mercado.png`: KPIs, filtros, actividad, regiones, contratos y proveedores.
7. `07-postulaciones.png`: cartera de propuestas, progreso y panel de inspeccion.
8. `08-workspace-postulacion.png`: oferta, RTM, archivos, mercado y avance del borrador.
9. `09-perfil-empresa.png`: identidad, lineas, capacidad y cobertura del radar.
10. `10-configuracion-alertas.png`: preferencias de alertas y vista previa de notificaciones.

## Lenguaje compartido

- lienzo ambiental azul hielo y lavanda;
- superficies glass para resumen, contexto e inspeccion;
- superficies blancas solidas para tablas, formularios y edicion;
- radios amplios, controles capsula y sombras frias suaves;
- violeta electrico para seleccion, negro para la accion principal;
- estados pastel e iconografia lineal consistente;
- jerarquia espaciosa sin perder densidad operativa.

Estas imagenes son referencias de composicion y estilo. Los textos, cifras y componentes definitivos deben conectarse a los datos y flujos reales documentados en `docs/stitch/buenapro-functional-context.md`.
